# Mascotte Maki

Illustrations du lémurien (Maki), générées puis découpées. Gardées ici pour les réutiliser (site vitrine, supports, autres postes).

- `originaux/` : fichiers d'origine, sans retouche. Les `Gemini_Generated_Image_*.jpeg` sont des planches de plusieurs poses ; les `.png` sont les poses découpées, fond transparent, environ 1400 à 1500 px.
- `public/maki/` : poses optimisées pour l'appli (WebP, 520 px de large au plus, fond transparent), noms sans accents.
- Correspondance pose et écran : `app/utils/maki-poses.ts`.
