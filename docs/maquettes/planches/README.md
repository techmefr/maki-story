Les trois thèmes de base ont été intégrés ; les saisons, événements et variations automatiques de décor sont la prochaine évolution. Les personnages sont fictifs : l’application conserve les vraies photos. Les salutations doivent rester Bonjour/Bonsoir selon l’heure locale, même si une ancienne étude affiche Coucou.

## Intégrité et périmètre

`manifest.json` conserve nom d’origine, date, taille et SHA-256 pour chaque copie. Les PNG ne sont ni recadrés ni recompressés. Les ressources isolées de feuillage et de décor font partie des recherches archivées. Aucun fichier de compte, secret, capture personnelle ou export de session n’est ajouté.

Les visuels récents sont les références à privilégier. Les anciennes recherches restent disponibles pour comparer l’évolution, sans remplacer les règles produit, les vraies données ou les critères d’accessibilité.
