Button atome
Une action principale par écran, en couleur pleine. Toujours une icône + un libellé. Rayon 24-28, padding 14-18, texte 18-21 / 700, ombre 4 px 5 px.
Variantes : principal jaune #FFC933 · valider menthe #4AD3A5 · enregistrer / retirer corail #FF7766 · secondaire bleu clair #CFE5FF · neutre blanc · désactivé gris. Props : variant, icon, label, disabled, onPress.
