# Studio (recording)

## Behavior
- Recording again an approved line creates a pending take for review; the child keeps hearing the approved take until validation.
- Same rule for the shared record flow and for a new language on a ready book.

## Design audit checklist
- One main action, visible secondary buttons with icon
- Big childlike icons, micro-animations
- No overflow at any text size, keyboard and remote focus
- prefers-reduced-motion respected
- Fredoka and Nunito, hard shadow 3px 3px 0 #1F1B3A
